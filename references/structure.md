# 構成診断

文の役割と配置から再読候補を抽出する。前後の主張を読み、保持・主張への組込み・重複の統合・削除を選ぶ。

## 規則

| ID | 候補になる形 | 読み直す内容 |
|---|---|---|
| S01 | 近接5段落のうち3段落以上が注意で終わる | 条件を該当する主張へ添える位置 |
| S02 | 実績や件数に伴う抽象的な区分指示 | 対象名・集計単位・状態での説明 |
| S03 | 近接箇所や履歴にある同じ注意 | 共通の方法と当日の条件 |
| S04 | 本文に混じる編集作業の報告 | 読者に必要な検証方法かどうか |
| S05 | 近接5段落で訂正型の対比が3文以上ある | 訂正する誤解や選択肢 |
| S06 | 複数の末尾に重なる評価・展望 | 結びが加える情報 |
| S07 | 同じ段落で条件や出典を言い直す | 既出の条件と追加情報 |
| S08 | 筆者が実施していないと添える断り | 情報に合う出典表示へ整える |
| S09 | 近接5段落に2文以上ある否定の結び | 結果・対象範囲・必要な対応で直接述べる |
| S10 | 仕様や動作の説明に付く資料名の前置き | 参照と条件を保って内容から述べられるか |

S01は2文以上の段落を対象にする。S06は異なる2節の末尾、または近接する3段落の末尾を見る。回数は試行用の初期値として置いている。

S02は候補語と報告の文脈を併せて拾う。入力の判定処理は技術的な意味を優先する。

S03は表現の一致や近さを使う。数値・識別子・検証対象も比べる。Git作業の進捗を扱う補助モードでは集計方法などの共通説明を日付間で比較する。使い方は[進捗記録の点検](../docs/progress.md)を参照する。

S07は同じ段落の直前3文と比べる。同じ文の後半に言い直しがある場合は前半も見る。環境・出典・検証範囲を型で拾い、比較した文と共通の語を表示する。新しい日時や数量、識別子、検証対象・状態がある文は別の情報として扱う。主体の省略や複雑な含意は前後から判断する。

## 原文の位置

文の解析は構成診断と語句診断で共用する。段落内の改行をつなぎ、引用番号や脚注を文数から外す。主な対応形式は次のとおり。

```text
[S1][S2]  [1]  [^note]  【1】
[出典](https://example.org)
<sup>1</sup>
```

数字の括弧と上付き文字は文末などの位置も確認する。普通のリンクはラベルを本文に残す。コード中の配列添字は元のまま扱う。

解析用の文字列では出典部分を同じ長さの空白にする。行番号と文字位置、表示する原文は維持する。コードフェンスは記号の種類と長さを比較する。コードと引用ブロックは修辞検査の対象外。表と箇条書きは文脈の表示に使う。

`--self-check` は引用符内の用語説明を隠す専用経路。通常の構成規則と行位置は共通である。

## 出力

同じ段落の指摘は一件にまとめる。JSONの `data.rules` に規則ID、`data.observations` に該当文と関連箇所を出す。S07の比較内容は `condition_overlap` に入る。

`span` と `related` はファイル名と文字位置を持つ。`start` は0始まり、`end` は範囲の直後。行・列は1始まりで、`text` は原文の該当箇所になる。

末尾位置は `paragraph_terminal / section_terminal / entry_terminal / document_terminal` で示す。`data.context` には直前の文や表を収める。画面では関連箇所を8件まで表示し、JSONには全件を保存する。

日付指定時のlintと観測値は当日の本文を対象にする。構成診断の版は `structure-4`、観測値の版は `prose-2`。コーパスとの比較条件は [Qiita集計](corpus-analysis.md) に記載した。

## 書き換えを進める条件

S08は単独でも `REWRITE` を返す。情報に合う出典表示へ直したらcheckのrunとverifyを実行する。独自検証の方法が依頼されている場合の指定は [校正の確認](review.md) に記載した。

S09は根拠や確認、代替を否定する結びの反復を拾う。失敗・未検証などの状態はその内容に応じて記す。文末を別の否定表現へ置き換えるより、報告された事実と必要な対応を整理する。

S10は文頭の資料名と説明表現から候補を拾う。手順・推奨・測定・見解・時点の手掛かりがある文や段落は除く。判定は語句による候補抽出で、内容の確かさは資料と照らして読む。規則の範囲と例は [情報の種類と出典](attribution.md) に記載した。
