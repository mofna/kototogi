# Qiita実データの比較

## 基準にしたデータ

主な参照元は逆瀬川ちゃんによるQiita API v2の記事収集と公開集計。2019〜2026年の各年8月を対象に70,524件を取得し、コード等を除いた地の文が300字以上ある日本語記事50,731件を分析している。

2019〜2022年はChatGPT公開前として扱われ、分析対象は次の22,476件。

| 年 | 分析対象 |
| --- | ---: |
| 2019 | 6,034 |
| 2020 | 7,076 |
| 2021 | 5,250 |
| 2022 | 4,116 |

2023〜2026年は28,255件。著者単位のブートストラップは1,000回。企業アカウントやAI関連タグを除いた条件、本文長を変えた条件でも主要結果はほぼ維持された。

別系統の比較にはImoto (2026)を参照した。対象は2020〜2022年のQiita/Zenn人間記事約700本と7種LLMの350生成文書。2026年6月のQiita 2,765件を全件取得したTabayashi (2026)は、近年の母集団規模や記事構造を確認する補助資料とした。

このスキルでは英語圏研究より上記の日本語技術記事データを優先する。

## 2019〜2022年と2026年の差

| 指標 | AI以前 | 2026 | 比率・差 |
| --- | ---: | ---: | ---: |
| 地の文の文字数 | 976字 | 1,914字 | 1.96倍 |
| 箇条書きの割合 | 8.9% | 16.4% | 1.84倍 |
| 太字 / 1,000字 | 1.26 | 3.83 | 3.04倍 |
| 1文あたり読点 | 0.63 | 0.95 | 1.51倍 |
| 見出しに「まとめ」 | 12% | 52% | +40pt |
| です・ます調の文 | 50% | 66% | +16pt |
| 文体混在の記事 | 48% | 31% | -17pt |
| 感嘆符 / 1,000字 | 0.93 | 0.29 | 約1/3 |
| 漢字率 | 19.0% | 24.4% | +5.4pt |

平均文長は35.4字から39.2字へ伸びたが、2019〜2022年から続く傾向でほぼ説明できた。文長そのものをAIらしさの主要指標にはしにくい。

読点は別で、文が少し長くなった以上の増加が見られる。スキルでは「文を短くする」より、読点で細切れにする癖を先に見る。

## 語彙の変化

AI以前はまれだった語のうち、2026年に広がった例がある。

- 実測: 0.1% → 7.2%
- 入口: 0.4% → 6.8%
- 事故: 0.3% → 6.8%
- 土台: 0.3% → 5.5%
- 別物: 0.4% → 5.5%
- 切り分ける: 0.5% → 5.2%
- 落とし穴: 0.3% → 4.0%
- 定石: 0.1% → 1.8%

単語単体を禁止語にはしない。2026年に増えた385語のうち197語は増加分の8割以上が2025〜2026年に集中している。特定語を機械的に避けても別の定型へ寄るだけなので、語が具体的な説明を担っているかを見る。

## 日本語らしい揺れを残す理由

日本語の計量文体研究では、読点の置き方や助詞分布に著者差が表れる。品詞系列・文節パターン・機能フレーズ・文末語も著者識別に使われている。これらは書き手の特徴として扱える。

国立国語研究所も、句読点の使い方は文章の目的や文体、読み手との関係で変わると説明している。横書きの私的文章には幅がある。

Qiitaではさらに、句点を打たず改行で文を切る書き手も一定数いる。技術記事だからといって公用文のように均一化すると、人間が元々持つ幅を削りやすい。

## 執筆への使い方

読点や語尾の選び方は書き手が選んだ文体見本を参考にする。文章量と段落の長さは説明する内容に合わせる。近年増えた語も、その語が表す処理や結果を前後から確認する。

章立てと説明の配置は [SKILL.md](../SKILL.md) に沿って点検する。構成診断では段落末の反復や共通説明を調べ、主張と条件を一緒に読める形へ整える。

## lintでの扱い

上の公開集計を同梱辞書の参照値として表示する。語句診断の分母や前処理と集計元の定義には差があるため、比較は参考表示とする。同梱の参照値は各年8月を対象とする公開集計に対応する。

特徴語は前後の技術的な説明と合わせて確認する。作用を表す語は、有効性や性能改善など資料にある結果に合う表現を選ぶ。同じ段落に複数の特徴が重なる場合は説明順も読み直す。

## prose-2の測定

現在のlintは文の解析を構成診断と共用する。引用番号と脚注を文数・文字数から外し、段落内の改行をつないで文を数える。前処理が変わったため、旧版lintの観測値と比べる場合は同じ原稿を再集計する。既存のコーパス平均は公開集計の値を参照表示する。生成時の目標は説明の明確さと書き手の文体に置く。
