# 情報の種類と出典

出典名を本文に置くかは、その情報の役割で決める。仕様や一般的な動作は対象を主語にし、根拠のリンクや参照番号を添える。

| 情報 | 書き方 |
|---|---|
| 仕様・構文・一般的な動作 | 対象を主語にして説明する |
| 個別の測定・調査結果 | 報告元と条件を示す |
| 選んだ資料の手順・推奨 | 紹介元や推奨した主体を示す |
| 見解・未確定の報告・直接引用 | 発信元と主張の確かさを保つ |

媒体の名前より文が伝える内容を見る。仕様の適用に必要な版や環境も本文へ添える。

## 点検の判断

S10は資料名付きの説明文を再読候補として示す。資料と前後を読み、出典名が情報を加えるか確かめる。S08で筆者の断りを削るときも同じ基準を使う。

段落の冒頭で帰属が伝われば内容を続ける。出典名を省いた後は参照の位置と適用条件を確認する。
