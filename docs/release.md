# 配布ガイド

配布するファイルは`release-files.txt`に相対パスで列挙する。新しいコードや文書を加えたら一覧も更新する。

## 内容の確認

READMEで目的と使い方が分かり、同梱の例から操作を追えるか読む。内部リンクは同梱ファイルへ、参考資料は確認できる出典へつなぐ。

個人の実パスや内部ホストと認証情報を検索する。原稿や検査記録は作業フォルダーで保管し、共有する記録では本文の抜粋も確認する。

公開者がライセンスを選び、著作権表示とともに`LICENSE`へ記す。採用したファイルを配布一覧へ加え、参照資料の扱いも確認する。

## ZIPを作る

スキルのフォルダーから実行する。

```bash
python -B -m unittest discover -s tests -v
python -B tools/build_release.py --output ../kototogi.zip
```

一覧のファイルと相対パスのSHA-256一覧を収録する。既存のZIPを保つため、出力先には新しい名前を指定する。

## GitHubへ配置する

ZIPを展開し、`kototogi/`の中身をリポジトリのルートへ置く。READMEと`SKILL.md`がルートに並ぶ構成になる。

展開先でテストを実行し、別の作業フォルダーからもCLIを呼ぶ。実行ログは配布フォルダーの外へ保存する。
